# 强电检修双6DOF机械臂仿真实验

这是一个面向本科实验教学的多页面 Streamlit 项目，按五个页面串联自然语言、双臂PDDL、左右臂运动规划和MuJoCo协作仿真：

1. 强电检修物体与目标区域配置；
2. 自然语言解析、PDDL domain/problem/plan 展示与修改；
3. PDDL动作到左右两组6DOF运动路点及关节参数的展开；
4. 双臂MuJoCo仿真执行；
5. 左右臂关节轨迹、双末端轨迹和物体最终位置分析。

## 五页实验流程

1. **场景配置**：选择强电检修物体、初始区域和 XYZ 坐标，并生成可复现的带电教学禁止区。
2. **PDDL 规划**：生成、查看和修改 PDDL；必须完成从 Domain/Problem 到路线参数的挑战填空，才能解锁连续运动。
3. **运动参数**：查看 PDDL 路线展开的左右臂路点，完成安全决策题，并在安全范围内修改q1～q6。
4. **仿真执行**：先完成执行前风险判断，再在MuJoCo中执行单/双臂动作序列。
5. **结果分析**：对比关节曲线、末端轨迹、双臂距离与带电区安全裕度，并给出教学评分。

> 本项目仅用于教学仿真，不构成真实带电检修的安全方案。

## Streamlit Community Cloud 部署环境

- 部署入口文件选择 `streamlit_app/app.py`（如果仓库根目录就是本目录，则选择 `app.py`）。
- 在 **Advanced settings** 中选择 **Python 3.12**，不要使用 Python 3.14。
- `packages.txt` 已包含 MuJoCo 离屏渲染需要的 OSMesa/OpenGL 系统库。
- Linux 云端没有桌面显示器，程序会在导入 MuJoCo 前强制切换为 OSMesa 离屏渲染；启动日志中应出现 `[robot_sim] MuJoCo offscreen backend: OSMesa`。macOS 和 Windows 本地运行仍使用原有渲染方式。
- 如果已经使用 Python 3.14 创建了应用，需要记录现有域名和 Secrets，删除该应用后用 Python 3.12 重新部署。Streamlit Cloud 目前不能直接修改已部署应用的 Python 版本。

## 配置 ChatGPT 调用

正式部署时不要把 API Key 写入源码或提交到 GitHub。项目按以下顺序读取配置：

1. Streamlit Secrets；
2. 同名环境变量；
3. `OPENAI_BASE_URL` 和 `OPENAI_MODEL` 使用项目默认值。

在 Streamlit Cloud 的 **App settings → Secrets** 中填写：

```toml
OPENAI_API_KEY = "填写重新生成的密钥"
OPENAI_BASE_URL = "https://api.apiyi.com/v1"
OPENAI_MODEL = "gpt-4.1"
```

仓库提供了 `.streamlit/secrets.toml.example` 作为字段示例；真正的 `.streamlit/secrets.toml` 已被 `.gitignore` 排除。由于旧密钥曾经出现在源码中，部署前应在接口服务商后台作废旧密钥并生成新密钥。

本地运行也可以使用环境变量：

```bash
export OPENAI_API_KEY="你的新密钥"
export OPENAI_BASE_URL="https://api.apiyi.com/v1"
export OPENAI_MODEL="gpt-4.1"

```

PDDL页面取消勾选“使用ChatGPT解析”后，可以使用本地关键词解析。可视化深度解读使用项目内置的`answer-me-with-html`，运行环境还需安装Node.js 20或更高版本。

## 双臂与剥线接线任务

- 蓝色机械臂为左臂，绿色机械臂为右臂；每条手臂各有6个可调关节和独立夹持状态。
- 普通任务根据目标工位自动选择更合适的机械臂；护罩和母排增加辅助稳定动作。
- 新增“待接导线”和“剥线接线协作工位”。推荐指令为“将待接导线完成剥线并接入端子插槽”。
- 该任务展开为左臂抓取并固定导线、右臂完成简化剥线、左臂对准并插入端子。
- 剥线仅通过状态和运动路点表达，不模拟柔性导线、刀具切削、压接力或真实带电作业。

## 带电作业教学抽象

- 可复现的带电教学禁止区生成在物体初始区与目标工位之间；直行路径会被拒绝，左/右侧绕行会生成入口和出口路点。
- 第1页可在安全范围内微调带电区中心X/Y、长宽倍率和安全边界；越出工作台时会回退到当前随机种子的可行几何。
- 工作台上方增加三根固定高压线，用独立安全包络限制“无限抬高”的错误绕行思路。
- PDDL 通过 `hazard-mapped`、`route-open`、`verify-safe-route` 和 `route-approved` 表达风险建图与路线批准；挑战填空的 route 将直接生成第三页路点。
- 连续运动的每个插值点都同时检查 MuJoCo 碰撞、带电教学区和上方高压线包络；发现错误会指明危险源及路点。
- 结果页绘制全程安全裕度，并结合轨迹效率、PDDL填空、运动决策和执行前判断生成课堂评价。
- 这些区域是教学几何抽象，不表示电场、电弧或任何法定安全距离。

## 错误示范

- 第4页的“错误示范与配置”下拉框集中提供“直线穿越带电区”、“过度抬高触及高压线包络”和“不合理关节角导致穿模”三个临时案例及对应参数。
- 第4页先让学生预测危险源和修改方法，再由MuJoCo播放错误轨迹的安全部分；进入1～3 cm预警范围或预计下一帧碰撞时，画面停在最后安全姿态。
- MuJoCo画面下方同步显示错误PDDL片段或运动层配置，标明出错的route、Z高度或关节扰动，并给出对应的正确修改。
- 拦截后可用同一机位播放推荐方案对比；临时示范不覆盖学生的正式方案，也不计入成绩。

## 设计说明

- PDDL 负责显示高层任务逻辑；内置教学规划器求解限定的 pick/place 问题，不依赖外部规划器程序。
- 实验台预置熔断器槽、端子槽、断路器安装位、检测点、开关操作点和护罩覆盖区；学生添加的是机械臂需要操作的对象。
- 页面显式展示“操作对象—推荐任务—固定设施—检修动作展开—重点参数”的对应关系。
- 每个PDDL初始语义区域都映射到明确的MuJoCo X/Y矩形边界；切换区域会同步更新坐标滑条，并阻止物体互相重叠。
- PDDL目标区域坐标直接由同一份区域配置生成，避免规划目标与场景显示使用两套坐标；仿真画面会高亮当前语义区域的真实边界。
- 教学工位使用蓝、灰、橙、黄四种色块和边框区分，画面下方直接说明颜色含义；当前对象关联工位会被高亮。
- 不同强电检修物体采用有区分度的教学动作模板，例如熔断器轴向拔出、端子排垂直插拔、断路器面板操作、验电笔与操作杆中部夹持、绝缘子侧向搬运等。
- PDDL 与运动参数页面均提供圆形问号提示；复杂概念可通过课程限定的 AI 深度解读生成结构化讲解页。
- 左右两套6DOF机械臂分别使用MuJoCo雅可比矩阵进行数值逆运动学，并检查两臂之间的碰撞。
- 学生可以修改末端路点、六个关节角、插值方式、安全高度和操作距离。
- q1～q6 仅允许在推荐 IK 解附近局部调节；保存前同时检查当前姿态及相邻两段插值轨迹。
- 场景、运动参数和执行页面提供预设机位、聚焦对象、方位角、俯仰角和缩放距离控制。
- 为避免穿模和不可达姿态，界面使用经过左右臂全任务测试的范围：安全高度 0.48～0.52 m、抓取偏移 0.075～0.090 m、轴向距离 0.08～0.14 m；末端路点和 q1～q6 也受到安全工作区限制。
- 每次执行前会逐帧检查整条插值轨迹；检测到桌面、柜体、自碰撞或越界时拒绝执行并指出发生问题的步骤。
- 本项目不实现工业级避障或真实强电作业控制。
